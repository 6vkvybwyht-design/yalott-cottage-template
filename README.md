# Приватна садиба Forest House

Сайт з онлайн-бронюванням для приватної садиби **Forest House**: три різні будинки, у кожного свій календар, свої ціни й своя сторінка.

1. **Апартаменти Green** — `/green`, фото в `static/img/obj1`
2. **Двоповерховий котедж** (до 6 гостей, з каміном) — `/cottage`, фото в `static/img/obj2`
3. **Будинок А-фрейм** (2 дорослих + 2 дітей, панорамне вікно з видом на гори) — `/a-frame`, фото в `static/img/obj3`

Бекенд: Flask + SQLite, `.env`, адмінка, Telegram. Розрахований на безкоштовний хостинг **PythonAnywhere**.

Що є на сайті:

- головна: банер з А-фреймом («від 2200 грн/доба»), переваги, три будинки, **територія** (чан, баня, басейн, альтанка — з фото), **домашнє харчування** (з фото), ціни, бронювання, правила, **відгуки гостей**, що поруч, контакти з Instagram і TikTok;
- окрема сторінка кожного будинку: опис, гості, зручності, ціни, галерея;
- **бронювання**: будинок → дати → гості → галочки «Чан» / «Баня» → автоматичний розрахунок зі знижкою за тривалість і передоплатою;
- святкові періоди «ціна за домовленістю»: замість суми сайт пише «Уточніть ціну у власника», заявку все одно можна надіслати;
- **адмінка** `/admin`: заявки з фільтром по будинку, зайнятість усіх трьох, ціни й знижки кожного будинку, ціни чану й бані, святкові періоди;
- **сповіщення в Telegram** про кожну заявку.

## Ціни

| Будинок | 1 доба | Знижка за тривалість |
|---|---|---|
| Апартаменти Green | 2500 грн | від 2 діб — 2200 грн/доба |
| Двоповерховий котедж | 4000 грн | від 2 діб — 3500 грн/доба |
| Будинок А-фрейм | 4000 грн | від 2 діб — 3500, від 5 діб — 3000 грн/доба |

Діє найбільший поріг, якого досягає бронювання: А-фрейм на 6 діб = 6 × 3000. Чан — 3000 грн, баня — 2000 грн за вечір (час необмежений), додаються до суми, якщо гість поставив галочку. Новорічні свята (30.12–07.01) — ціна за домовленістю.

Усе це **змінюється в адмінці → «Ціни»**: ціна за добу, пороги діб (кнопка «+ додати знижку»), ціни чану й бані, святкові періоди (для одного будинку чи всіх, з ціною або «за домовленістю»). Значення в `site_content.py` — лише стартові для нової бази.

## Що ще замінити

| Що | Де |
|---|---|
| Телефон, Viber, адреса, карта | `site_content.py` → `SITE` (позначено `# ЗАГЛУШКА`) |
| Відгуки гостей (3 заглушки) | `site_content.py` → `REVIEWS` |
| Описи будинків, кількість гостей у Green, зручності | `site_content.py` → `OBJECTS` |
| Передоплата, час заїзду/виїзду, правила будинку, «що поруч» | `site_content.py` → `RULES`, `HOUSE_RULES`, `NEARBY` |

## Фото

- Оригінали — `photos/original/<папка>` (не змінюються).
- Оброблені для сайту — `static/img/obj1`, `obj2`, `obj3`, `territory`, `food`: яскравість, контраст і насиченість трохи підняті (+10–15 %, без пересвітів), ширина до 1600 px, JPEG 82, метадані (GPS) прибрані. Перше фото в папці — обкладинка; іншу можна задати ключем `"cover"` у `OBJECTS` (котедж: `03.webp`, вітальня з каміном). Банер головної — `SITE["hero_photo"]` (`img/obj3/22.webp`, А-фрейм узимку). Підписи — `captions.txt` у тій самій папці.
- Логотип — `static/img/logo.png` (темний, у шапці), `logo-light.png` (світлий, у футері й на темних шапках), `static/favicon.png`.

Нові фото: покладіть оригінали в `photos/original/<папка>` і запустіть

```bash
python tools/process_photos.py
```

Порядок і підписи задаються на початку `tools/process_photos.py` (ORDER). Можна й просто класти готові фото в `static/img/<папка>` — сайт підхопить їх автоматично в порядку імен файлів.

## Запуск на своєму комп'ютері

Потрібен Python 3.9 або новіший.

```bash
python -m venv .venv
```

Увімкніть середовище. Windows: `.venv\Scripts\activate`, macOS / Linux: `source .venv/bin/activate`.

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

```bash
python app.py
```

Сайт — http://localhost:5000, адмінка — http://localhost:5000/admin (демо-доступ `admin` / `forsethouse2026`, поки в `.env` не задано свій пароль).

База `instance/forsethouse.db` створюється автоматично. Базу попередньої версії (будні/вихідні) сайт оновлює сам при запуску: бронювання й закриті доби зберігаються, ціни беруться нові.

### Перевірка

```bash
python -m unittest discover -s tests -v
```

Для обробки фото потрібен Pillow (`pip install pillow`) — сайту він не потрібен.

## Налаштування (файл `.env`)

| Змінна | Що це |
|---|---|
| `SECRET_KEY` | Довгий випадковий рядок для захисту входу. Згенерувати: `python -c "import secrets; print(secrets.token_hex(32))"` |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | Логін і пароль адмінки. Без них діє демо-доступ `admin` / `forsethouse2026` |
| `DEMO_DATA` | `1` — демо-зайнятість листопада–грудня 2026; `0` — без неї. Діє лише при створенні нової бази |
| `SESSION_COOKIE_SECURE` | `1` на сайті з HTTPS (PythonAnywhere), `0` на своєму комп'ютері |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Бот від [@BotFather](https://t.me/BotFather) і чат власника для заявок |
| `TIMEZONE` | За замовчуванням `Europe/Kyiv` |

Змінити пароль адмінки:

```bash
flask --app app set-password admin
```

## PythonAnywhere

1. У Bash-консолі: `git clone <репозиторій> ~/forsethouse-demo`, потім `cd ~/forsethouse-demo && pip3 install --user -r requirements.txt`.
2. `cp .env.example .env` і заповніть (`SESSION_COOKIE_SECURE=1`, `DEMO_DATA=0` для бойового сайту).
3. Вкладка **Web** → Add a new web app → Manual configuration → Python 3.10+.
4. `cp ~/forsethouse-demo/pythonanywhere_wsgi.py /var/www/$(whoami)_pythonanywhere_com_wsgi.py`
5. Static files: URL `/static/` → `/home/<логін>/forsethouse-demo/static`.
6. **Reload**.
