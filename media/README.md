# Оригінали фото

Сюди кладуться фото «як є» — з телефона чи фотоапарата. Сайт їх не показує напряму:
команда `python manage.py photos` робить з них легкі WebP у `static/media/`.

```
media/
  objects/<id об'єкта>/   фото об'єкта: 01.jpg, 02.jpg… (перше — обкладинка)
  hero/                   одне фото для банера головної
  gallery/                територія, краєвиди, кухня
  extras/                 фото послуг, ім'я файлу = id послуги: chan.jpg, banya.jpg
  brand/                  logo.png, logo-light.png, favicon.png — копіюються без змін
```

`<id об'єкта>` — це поле `id` з `config/site.yaml`.
Порядок фото на сайті — за іменами файлів. Підписи (необов'язково) — файл
`static/media/<папка>/captions.txt`, рядки `01.webp = Вітальня з каміном`.

Оригінали **не зберігаються в git** (вони важкі) — тримайте їх у себе.
У git ідуть лише оброблені фото зі `static/media/`.
